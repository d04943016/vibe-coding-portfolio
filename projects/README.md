## README Public-Safety Check

When preparing a README, check and handle:

- API keys, tokens, secrets, passwords, and credentials
- Private repository URLs, internal deployment URLs, and database connection strings
- Client names, user names, email addresses, phone numbers, and addresses
- Internal business workflows, unreleased product strategy, contracts, and pricing information
- Screenshots, debug logs, and error traces that are not suitable for public release
- Links pointing to source code in the original private project

## Image Rules

- Store images in the project-specific `assets/` folder.
- Use relative paths in README files, for example `![Dashboard](assets/dashboard.png)`.
- If an image filename contains spaces or special characters, rename it to a stable GitHub-friendly filename.
